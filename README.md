# wavelength-selective-film_vs_No_countermeasures_new

放射冷却フィルムの効果を比較する事前シミュレーション

夜間放射促進フィルム　vs　無対策の比較対照　のアルミ押し出し屋根パネル（シルバー色）の3日間の我孫子での実験を前提として事前シミュレーションのグラフ

## 🎯 目的
夏季の屋根面を天空の窓に向かって、宇宙空間へ効率的に建物内部の熱を放熱するためのシステムを考案中です。  
その初歩的な放射フィルムを張り付けたもの（wavelength-selective film）と、なにも張らないアルミ素材（No countermeasures）で、  
**同じシルバー色の屋根材を比較対象とした実験の事前シミュレーションプログラム**を作りました。
作ったのが3ケ月ほど前で、こまかな設定内容をまだ点検していませんが、たぶん内部側の蓄熱容量が大きいため、
外気温変動は、昼間太陽の日射を受けている影響よりも、夜間の放熱量がかなり大きいために昼間の表面温度の急激な上昇が
見た目では、かなり低く抑制されているように見えます。

---

## 🧪 実行手順
1. 上の **「wavelength-selective film_vs_No_countermeasures_new.ipynb」** をクリック
 **左上の三角（▶）ボタン** を押して実行します。
2. Notebook 下部に表示される **内部発熱量（デフォルト 50W）** の入力欄に  
   任意の値をキーボードで入力し、**Enter** を押します。
3. プログラム内に既に実験場となる **我孫子市の 7 月の 3 日間の実際の気象データ**が記載されています。  
   SPACECOOL とアルミ素材の放射冷却挙動を比較シミュレーションします。

---

## 📊 この Notebook でわかること
- 放射冷却フィルム（wavelength-selective film）の効果の有無による温度挙動の違い  
- 内部発熱量を変えたときの屋根面温度の応答  
- 実際の気象データを使った、より現実的なシミュレーション結果  
- 実験前に「どの程度の差が出るか」を把握するための予測
